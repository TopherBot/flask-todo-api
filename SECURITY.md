# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability, please email **security@yourdomain.com** with a detailed description. We will acknowledge receipt within 48 hours and work with you to resolve the issue.

### Preferred Disclosure Process
1. **Do not** post details publicly.
2. Include steps to reproduce, affected versions, and any relevant logs.
3. We will provide a CVE identifier if applicable.

## Supported Versions
We currently support the `main` branch. Older releases may receive limited support.
